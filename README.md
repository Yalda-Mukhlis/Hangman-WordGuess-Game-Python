# 🎯 Hangman-Game
**Level: Beginner+**

A Python implementation of the classic Hangman word-guessing game.  
This project uses loops, conditional logic (if/elif/else), list operations, string processing, ASCII-art stages, and step-by-step error tracking — making it an excellent beginner+ project for building interactive console games and improving logical problem-solving.

---

## 📝 Description
The Hangman game challenges the player to guess the hidden word one letter at a time.  
With each wrong guess, a new part of the hangman figure appears on the screen.  
The game ends when the player either completes the word or the hangman drawing is fully constructed.

This version of Hangman includes:
- Random word selection  
- ASCII-art representing each stage  
- Letter tracking  
- Input validation  
- Real-time game-state updates  

---

## 💡 Features
- Random word generation  
- Progressive hangman ASCII-art stages  
- Tracks guessed letters  
- Detects win/lose conditions  
- Input validation for non-letter characters  
- Clean and simple console interface
